# 📋 README.md - CarWash Chameleon

## Sistema de Gestão para Lavação Automotiva

---

### 🚗 Sobre o Projeto

O **CarWash Chameleon** é um ERP completo desenvolvido para gestão de lavações automotivas, oferecendo controle operacional em tempo real, gestão de filas estilo Kanban, controle financeiro e multi-usuário com permissões granulares.

Desenvolvido para atender desde pequenos lava-rápidos até operações de médio porte, o sistema proporciona eficiência operacional e visibilidade total do negócio.

---

### ✨ Funcionalidades

#### 📊 Dashboard Administrativo
- Métricas em tempo real (faturamento, ordens, fila)
- Gráficos de performance semanal
- Ranking de serviços mais vendidos
- Visão geral do negócio

#### 🎯 Kanban Board (Fila de Serviços)
- Visualização em colunas (Fila → Execução → Finalizados)
- Arrastar e soltar ordens entre colunas
- Priorização de serviços (Baixa, Normal, Alta, Urgente)
- Atribuição de boxes de lavagem

#### 👥 Gestão de Clientes
- Cadastro completo com dados pessoais
- Histórico de serviços
- Programa de fidelidade (pontos)
- Veículos múltiplos por cliente
- Registro de danos pré-existentes

#### 🚗 Gestão de Veículos
- Cadastro de múltiplos veículos por cliente
- Fotos do veículo (antes/depois)
- Registro de danos com fotos
- Histórico completo de serviços
- Placa no padrão Mercosul

#### 🔧 Gestão de Serviços
- Serviços configuráveis (Lavagem, Higienização, Polimento, Vitrificação)
- Categorias personalizáveis
- Tempo estimado por serviço
- Preços e custos
- Margem de lucro calculada automaticamente

#### 💰 Gestão Financeira
- Múltiplos métodos de pagamento (Dinheiro, Pix, Débito, Crédito)
- Parcelamento no cartão
- Descontos
- Histórico de pagamentos
- Fechamento de caixa diário
- Relatórios financeiros

#### 👨‍💼 Controle de Funcionários
- Múltiplos níveis de acesso (Admin, Gerente, Operador, Lavador, Caixa)
- Permissões granulares por cargo
- Controle de salários e data de admissão
- Desempenho por funcionário
